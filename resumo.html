🌟 Pronomes pessoais — caso RETO e caso OBLÍQUO

Caso RETO (função de SUJEITO — quem pratica a ação)
PessoaSingularPlural
1ª (quem fala)eunós
2ª (com quem se fala)tuvós
3ª (de quem se fala)ele / elaeles / elas
Caso OBLÍQUO (função de COMPLEMENTO — quem recebe a ação)
PessoaSingularPlural
1ªme, mim, comigonos, conosco
2ªte, ti, contigovos, convosco
3ªse, si, o, a, lhese, si, os, as, lhes
Caso reto
clique para virar 🔄
É o sujeito da frase (quem pratica a ação). Dica: pergunte "Quem pratica a ação?". Ex.: "Eu li o livro."
Caso oblíquo
clique para virar 🔄
É o complemento (quem recebe/sofre a ação). Ex.: "Minha mãe me chamou.", "João lhe deu o livro."
eu/tu × mim/ti
clique para virar 🔄
eu, tu = reto (sujeito). mim, ti = oblíquo. Depois de "para" quase sempre é mim/ti: "É para mim."
Substituir sem repetir
clique para virar 🔄
Use o oblíquo no lugar do nome repetido: "Vi a professora e a cumprimentei." (o/a/os/as, lhe/lhes).
📌 Dica de prova: o reto é o protagonista (faz a ação); o oblíquo é o coadjuvante (recebe a ação). Se puder ser sujeito → reto. Se completa o verbo → oblíquo.
⚠️ Pegadinha: "para eu" está errado. O certo é "para mim". ("Entre mim e você", nunca "entre eu e você".)

VOSSA × SUA
clique para virar 🔄
VOSSA = falando COM a pessoa ("Vossa Excelência aceita?"). SUA = falando SOBRE a pessoa ("Sua Excelência viajou.").
Verbo na 3ª pessoa
clique para virar 🔄
Mesmo com "Vossa", o verbo vai na 3ª pessoa: "Vossa Excelência está presente." (nunca "estais").
Os "campeões" da prova
clique para virar 🔄
Papa → Vossa Santidade. Cardeal → Vossa Eminência. Rei → Vossa Majestade. Reitor → Vossa Magnificência.
📌 Dica de prova: VOSSA = falaVando (falando COM). SUA = Sobre (falando sobre). Guarde por essa letrinha! 💡
⚠️ Pegadinha: "você" também é tratamento e pede o verbo na 3ª pessoa: "Você estuda" (não "você estudas").

🔭 Pronomes DEMONSTRATIVOS

Onde está a coisa? (posição no espaço)
PosiçãoMasc./Fem.NeutroJeito fácil
Perto de quem FALA (1ª)este, esta, estes, estasisto"aqui comigo"
Perto de quem OUVE (2ª)esse, essa, esses, essasisso"aí com você"
LONGE dos dois (3ª)aquele, aquela, aqueles, aquelasaquilo"lá, distante"
ESTE
clique para virar 🔄
Perto de quem fala ("aqui comigo"). Ex.: "Este livro está na minha mão."
ESSE
clique para virar 🔄
Perto de quem ouve ("aí com você"). Ex.: "Esse caderno aí é seu?"
AQUELE
clique para virar 🔄
Longe dos dois ("lá, distante"). Ex.: "Aquele prédio fica do outro lado da rua."
No texto: retomar
clique para virar 🔄
Aponta para algo já dito. "Maria ganhou um livro. Esse livro é de aventura." (esse retoma "livro").
No texto: antecipar
clique para virar 🔄
Anuncia algo que vem depois. "Isto é importante: respeite os animais." (isto antecipa a ideia).
📌 Dica de prova: ESTE = perto de quem fala. ESSE = perso de quem escuta. AQUELE = lá longe. Repita 3 vezes e não erra mais! 😄
⚠️ Pegadinha: isto, isso, aquilo são neutros — não têm plural nem feminino. Servem para o que a gente não nomeia: "O que é isso?"

📚 Glossário rápido

PalavraO que significa
PronomePalavra que substitui ou acompanha o substantivo (o nome), indicando as pessoas do discurso.
Pessoas do discurso1ª = quem fala (eu/nós); 2ª = com quem se fala (tu/vós); 3ª = de quem se fala (ele/ela).
Caso retoPronome pessoal que funciona como sujeito (quem pratica a ação).
Caso oblíquoPronome pessoal que funciona como complemento (quem recebe a ação).
Pronome de tratamentoForma respeitosa/formal de se dirigir a alguém, conforme a posição da pessoa.
Vossa / SuaVossa = falando COM a pessoa; Sua = falando SOBRE a pessoa.
Pronome demonstrativoIndica e localiza coisas conforme a posição (perto/longe) e também no texto.
Retomar (no texto)Quando o demonstrativo aponta para algo já dito antes.
Antecipar (no texto)Quando o demonstrativo anuncia algo que ainda vai ser dito.
NeutroAs formas isto, isso, aquilo (sem plural nem feminino).
